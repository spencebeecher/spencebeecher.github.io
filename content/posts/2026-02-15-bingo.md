[Bingo](/bingo/) started as a way to make a Halloween movie night more fun. It is a set of themed 5×5 cards you play while watching something — the squares are the things that are going to happen anyway.

![The bingo index, laid out as a bingo card with a game in each square](../assets/misc/bingo.jpg)

*The index is itself a bingo card. Every square is a game.*

Twelve games are on the card: Christmas, Halloween, Spooky, Monster, Slasher, Stranger Things, Football, Hockey, Romcom, Western, Action and a kids' one. The centre square is FREE, same as every card inside.

Each card has a **Shuffle** button, because the point is that two people watching the same film get different boards.

The pages are plain HTML with nothing behind them. A Python script builds each one from a shared template and that theme's list of squares, so adding a theme is a list of phrases rather than a page. There is a small local server for previewing before they go up.

Where it falls short: the squares are fixed per theme, so the second time through a movie the card is familiar. Sizing the phrases to the square is also still by eye.
